## Minhas atividades

Minhas entregas estão em `Atividades/`, numeradas na ordem das aulas. Cada pasta abre com um README que explica o que foi feito, e os arquivos da atividade ficam na subpasta `entrega/`. As pastas `Unidade1_LinguagensFormais`, `Unidade2_GramaticasFormais`, `Expressoes_Regulares` e `InteligenciaArtificial` têm o material da professora e vêm do repositório original. A exceção são as notas do Capítulo 1, que ficaram em `InteligenciaArtificial/Atividades/` porque esse foi o caminho pedido no enunciado. A pasta 06 explica isso e aponta para lá.
